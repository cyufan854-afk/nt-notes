> For agentic workers: implement inline with executing-plans; one final independent review.

Goal: implement the user's five requested changes on v0.2 without losing resumability and bounded budgets.
Architecture: retain provider transports and SQLite; add a framed response protocol, per-branch reviews, per-finding batch manifest, and a Docker-only execution module. Reports assemble reviewed text deterministically.
Tech Stack: Python 3.10+ stdlib; optional local Docker Engine and pre-pulled python:3.12-slim image for execution.
Spec: user's five numbered requirements in this conversation; decisions below.

## Constraints and decisions
- JSON metadata contains enums, IDs, issue severity; all mathematical free text and scripts remain raw Markdown.
- Each review call judges one named branch. Only revise branches are retried; approve with advisory issues becomes approve_with_notes, explicit blocking issues still force revise.
- JSONL accepts location/excerpt/concern or 位置/原文片段/疑点, optional id. Input JSONL itself must be serialized correctly; reject decoded unexpected controls in excerpts and explain escaped backslashes.
- Batch children each freeze a single finding plus optional explicitly supplied context files; budgets per child. Parent records IDs before execution and resumes children, never rebuilding completed children.
- Five outward finding states are model-assisted assessments, not mathematical certification. Conflicts and missing execution yield 待人工; evidence status requires real completed execution + review of actual stdout.
- Docker sandbox only; --network none, no host file bind mounts, script via stdin, read-only root, tmpfs workspace, resource limits, no added capabilities. No unsafe host fallback. Missing daemon/image => unavailable and 待人工 when execution requested.
- Default timeouts: planner/reviewer 600s, analysts/revision 1200s; codex provider 1200s; specific role may override. No auto retries.
- v0.2 tasks with unfinished legacy protocol cannot resume under v0.3; explicit clear error, original version remains available.

## Review focus
LaTeX unchanged through storage/report; malicious/duplicate frames; partial branch revision/resume; batch interruption and malformed last line; sandbox cleanup/output cap/missing image; model claims of execution without records; conflicts between branch outcomes.
